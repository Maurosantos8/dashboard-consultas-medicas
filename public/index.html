Painel de Consultas Médicas

Clínica de Chimoio, Manica. Dados em tempo real da base de dados MySQL no Railway.

Consultas por especialidade

SQL por trás deste gráfico
SELECT e.nome_especialidade, COUNT(c.id_consulta)
FROM especialidade e
LEFT JOIN medico m ON m.id_especialidade = e.id_especialidade
LEFT JOIN consulta c ON c.id_medico = m.id_medico
GROUP BY e.id_especialidade, e.nome_especialidade;

Consultas por estado

SQL por trás deste gráfico
SELECT estado, COUNT(*) FROM consulta GROUP BY estado;

Consultas por dia

SQL por trás deste gráfico
SELECT data_consulta, COUNT(*) AS total
FROM consulta
GROUP BY data_consulta ORDER BY data_consulta;

DataHoraPacienteMédicoMotivo
SQL por trás desta tabela
SELECT c.data_consulta, c.hora_consulta, p.nome, m.nome, c.motivo
FROM consulta c
JOIN paciente p ON c.id_paciente = p.id_paciente
JOIN medico m ON c.id_medico = m.id_medico
WHERE c.estado = 'Marcada' AND c.data_consulta >= CURDATE()
ORDER BY c.data_consulta, c.hora_consulta LIMIT 10;
